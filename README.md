# Associação Amizade do Bem

Site institucional desenvolvido como MVP (Produto Mínimo Viável) para a Associação Amizade do Bem, localizada em Gravataí – RS.

## Sobre o projeto

O objetivo do site é apresentar a associação, divulgar suas iniciativas sociais e facilitar o contato com pessoas interessadas em conhecer, apoiar ou participar das ações.

## Funcionalidades

- Página inicial com apresentação da associação.
- Seção sobre a instituição.
- Divulgação de projetos e ações sociais.
- Apresentação de eventos.
- Formulário demonstrativo de doações.
- Seção de contato.
- Layout adaptável para computadores e dispositivos móveis.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
